# 부서 문서 사전 조사

번호가 붙은 입력 문서와 `templates/pre_research.md`를 사용해 사전 조사 요약 초안을 작성한다.

- 문서에 명시된 업무, 절차, 시스템, 데이터 원천만 정리한다. 문서에 없는 담당자·빈도·절차를 추정하지 않는다.
- 후보 업무마다 관련 문서의 절차 발췌와 문서 근거를 붙인다. 인용은 해당 파일의 지정 줄 범위 안에서 연속된 원문 그대로 가져온다.
- 사전 조사 확인 항목은 문서에 업무가 나오지만 빈도, 담당자, 사용 시스템, 절차 가운데 하나 이상이 명시되지 않은 경우에만 만든다. 항목에 누락된 요소를 구체적으로 적는다.
- 시스템과 데이터 원천은 문서에서 확인된 것만 정리한다.
- 산출물의 YAML front matter에서 `status: reviewed`와 `followup_items`를 채운다. 각 `followup_items`는 `content`와 `missing_fields`를 포함한다. 확인 항목이 없으면 빈 목록 `[]`을 쓴다.
- `출처`, `인터뷰 식별자`, `실행 버전`, `엔지니어 확정` 필드를 유지한다. 아직 입력되지 않은 메타데이터는 `[확인 필요: ...]`로 둔다.
- 아래 템플릿의 제목과 섹션 순서를 바꾸거나 빼지 않는다. 출력은 완성된 Markdown만 반환한다.
