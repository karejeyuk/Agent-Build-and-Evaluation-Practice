# 설계서 초안 작성

입력은 엔지니어가 착수를 확정한 업무 카드와 종합 순위표다. 확정되지 않은 업무는 설계 대상으로 취급하지 않는다.

1. 카드의 업무 사실과 근거, 순위표의 승인 조건을 읽는다.
2. `prompts/draft.md`에 따라 9개 목차의 JSON 초안을 작성한다. 각 목차의 세부 필드는 빠짐없이 포함한다. 정보가 없으면 `[확인 필요: ...]` 또는 `[정보 부족: 2단계 보강 필요]`로 남긴다.
3. 사실 필드에는 카드의 근거 객체를 연결한다. 새 사실, 시스템, 처리 절차를 지어내지 않는다. 제안은 제안으로 표시한다.
4. JSON을 `design.json`으로 저장하고 다음을 실행한다.

   `python3 skills/design-doc/design_doc.py design.json --output outputs/<파일명>.md`

5. 스크립트가 19개 세부 항목의 미확인 비율과 필수 승인 단계를 확인한다. B1형 또는 오류 영향도 1~2점이면 사람 승인 문구가 없을 때 스크립트가 추가한다. 템플릿 목차가 맞지 않으면 저장하지 않는다.
6. 작업 공간 루트에서 `python3 core/validate.py evidence --input <design.json> --transcript <원문.txt> [--documents <번호붙인문서.json>]`를 실행해 사실 인용을 대조한다. 공통 검증기는 작업 공간 루트의 `core/`에 있다. 실패하면 실패 항목만 한 번 고쳐 다시 검사한다.

산출물은 초안이다. 엔지니어 확정란에는 엔지니어가 `승인`을 기록한다.
