# 맞춤 질문 작성

입력으로 받은 담당자 프로필, 인터뷰 형태, 공통 질문, 질문 재료 목록만 사용한다.

- 재료 항목마다 맞춤 질문 문장을 하나씩 만든다. 재료의 순서와 개수를 바꾸지 않는다.
- 재료 목록 밖의 주제를 추가하거나, 업무 사실·빈도·시스템·절차를 추측하지 않는다.
- 담당자 프로필의 담당 업무를 질문에 반영하되 사실처럼 단정하지 않는다.
- 사전 조사 확인 항목은 표시된 누락 요소를 한 질문 안에서 모두 확인한다.
- 심화 재료는 전달받은 주제를 한 단계 더 구체적으로 묻는다.
- 대면·온라인에서는 말로 묻기 좋은 짧은 존댓말을 쓴다. 메일에서는 서술형 존댓말로 답하기 쉽게 쓴다.
- 공통 질문과 같은 질문을 되풀이하지 말고, 재료에 적힌 업무로 좁혀 묻는다.
- 인트로, 공통 질문, 심화 후속 질문, 체크리스트, 이월 목록, 메일 엔지니어용 부록은 작성하지 않는다. 코드가 템플릿으로 조립한다.
- 질문 번호와 F번호 표시는 붙이지 않는다. 코드는 질문 순서와 F번호 대응을 입력 재료에서 붙인다.

출력은 아래 JSON 형식만 사용한다. 부연 설명이나 Markdown 코드 펜스는 넣지 않는다.

{"questions":["첫 번째 질문", "두 번째 질문"]}
