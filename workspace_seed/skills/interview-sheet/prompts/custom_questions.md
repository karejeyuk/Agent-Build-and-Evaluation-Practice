입력: [담당자 프로필] [인터뷰 형태] [공통 질문 8개(참고용, 다시 쓰지 말 것)] [코드가 정한 맞춤 질문 개수] [코드가 배분한 재료 항목 목록: 종류(필수 확인 주제, 필수 확인 주제(심화), 사전 조사 확인 항목, 확인 목록 항목)와 내용, 사전 조사 확인 항목은 빠진 요소 포함, 확인 목록 항목은 F번호 포함]

지시: 재료 항목마다 질문을 하나씩, 지정된 개수만큼 재료 순서대로 만들어라. 필수 확인 주제(심화)는 같은 주제를 한 단계 더 파고드는 질문으로 만들어라. 사전 조사 확인 항목은 빠진 요소를 모두 묻는 질문 하나로 만들어라. 공통 질문과 같은 내용은 되묻지 말고 담당 업무나 항목 이름으로 좁혀 물어라. 재료 목록에 없는 주제로 질문을 만들지 마라. 업무 사실을 단정하지 마라. 형태가 대면이나 온라인이면 말로 묻기 좋은 짧은 존댓말 질문으로, 메일이면 글로 답하기 좋은 서술형 존댓말 질문으로 써라. 질문 번호와 (F번호)는 코드가 붙이므로 쓰지 마라. 인트로 멘트, 공통 질문, 심화 후속 질문, 마무리 체크리스트, 이월 블록, 엔지니어용 부록은 코드가 채우므로 쓰지 마라.

출력은 아래 JSON 하나다. 설명과 코드 펜스는 쓰지 않는다.
{"questions":["첫 번째 재료의 질문","두 번째 재료의 질문"]}
