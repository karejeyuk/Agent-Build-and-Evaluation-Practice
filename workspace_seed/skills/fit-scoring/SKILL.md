# 적합성 평가

## 절차

1. 검토 완료된 사전 조사 요약서와 엔지니어 확정이 기록된 카드만 입력으로 받는다. 카드와 확정 상태를 확인한다.
2. 각 업무마다 최신 회차 카드를 고른다. 입력에 인터뷰 식별자 회차나 직전 카드 연결이 없으면 임의로 병합하지 않고 엔지니어 확인을 요청한다. v3의 공통 카드는 그 카드의 관련 담당자에 연결된 개별 카드들을 대체한다.
3. `rules.md`를 읽고 채점 대상 A형·B1형 카드별로 반복성을 제외한 3개 기준의 점수(1~5)와 카드 원문 근거를 `prompts/select.md` JSON 계약으로 작성한다. 판단이 불가능하면 점수를 만들지 않고 `[확인 필요]`로 둔다.
4. `python3 skills/fit-scoring/scoring.py <선택결과.json> --output <점수계산.json>`을 실행한다. 코드는 카드 선택, 반복성, 점수·총점·등급, 상한, 절감 시간, 정렬을 계산한다.
5. 작업 공간 루트에서 `python3 core/validate.py evidence --input <선택결과.json> --transcript <원문.txt> [--documents <번호붙인문서.json>]`를 실행해 인용을 검증한다. 실패한 점수 근거는 재생성 후에도 실패하면 해당 기준을 `[확인 필요]`로 바꾸고 채점기를 다시 실행한다.
6. `prompts/summary.md`로 코드가 고른 상위 3개(또는 더 적은 수)의 추천 근거 요약만 작성한다. 계산된 점수와 등급을 바꾸지 않는다.
7. `templates/scoring_table.md`에 맞춰 Markdown을 저장한다. B2형 표준화 권고는 엔지니어가 B2형으로 확정한 카드 것만 붙인다.

## 엔지니어 확정

순위표는 초안이다. 업무별 확정은 `즉시 착수`, `검토 후 착수`, `착수 보류`, `다음 회차 확인` 중 엔지니어가 기록한다. 평가 불가는 다음 회차 확인 또는 착수 보류만 허용한다. 오류 영향도 1~2점은 즉시 착수 불가다.
